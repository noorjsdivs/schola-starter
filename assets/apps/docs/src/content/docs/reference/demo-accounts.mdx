`pnpm seed` fills an empty database with a complete demo platform: a Super
Admin, one fully set-up school (**Greenfield International School**) with a
sign-in for every role, and three more schools in other states so every
platform screen has something to show. This page lists every account it
creates and what each one is good for — use it when you record a walkthrough
or test a feature as a particular role.

How to run the seed, its options and what data it creates are covered in
[Demo data](/setup/demo-data/).

The school app's dashboard at <Route path="/app" /> adapts to the person:
roles that can read the school profile (School Admin, Principal, Vice
Principal, Accountant) see the school dashboard with live attendance and fee
figures; teachers, students, parents and staff see their own member
dashboard. The sidebar shows only what the role's permissions allow.

## The four demo schools

| School | Type | Status | Owner sign-in | What it is for |
|---|---|---|---|---|
| Greenfield International School | `school` | `active` | `admin@greenfield.example` | The fully set-up school: 500 students, 30 teachers, 10 staff, every module filled. |
| Riverside Academy | `school` | `pending_approval` | `owner@riverside.example` | An application to approve or reject on <Route path="/platform/approvals" />. Applied 3 days ago. |
| Lakeside Coaching Centre | `coaching` | `pending_approval` | `owner@lakeside.example` | A second pending application. Applied 1 day ago. |
| Hilltop College | `college` | `suspended` | `owner@hilltop.example` | A suspended tenant (reason: "Subscription payment overdue by 60 days."), to show reactivation. |

All four use the locale `en-US` and the currency `USD`. The Super Admin has a
"New school application" notification for each pending school.

## Changing or resetting the accounts

- **Another password:** `pnpm seed -- --reset --password 'Another-Pass1'`. It
  must pass the same strength rules as sign-up. The seed then prints "(the
  --password you passed)" instead of the password.
- **Start over:** `pnpm seed -- --reset` removes the demo schools (with
  everything stored under them) and every account on the demo domains, then
  seeds a fresh copy. `sunrise.example` — the [tutorial](/tutorial/overview/)'s
  Sunrise Academy — is one of those domains, so the reset removes that school
  too. Other schools and accounts are untouched; audit log entries stay.
- **Fewer or more students:** `--students 20` to `--students 600`. The
  student and parent names (including Adam Singh and Sofia Singh) are only
  guaranteed with the default 500.
- **Production:** the seed refuses to run with `NODE_ENV=production` unless
  you pass `--allow-production` **and** your own `--password`. Never leave the
  public demo password on a real deployment.

<Aside type="tip" title="Password reset emails">
"Forgot?" works for demo accounts, but the addresses are not real inboxes. In
development the reset link appears in the API log (console email transport).
See [Email](/setup/services/email/).
</Aside>

## Under the hood

- <SourceFile path="apps/api/src/seed/demo-school.ts" symbol="buildDemoDataset" /> — builds every account, school and record as plain documents (no database access). `DEMO_DEFAULT_PASSWORD`, `DEMO_EMAIL_DOMAINS` and the teacher email rule live here.
- <SourceFile path="apps/api/src/seed/run-demo-seed.ts" symbol="runDemoSeed" /> — writes the dataset, creates the roles for the active and suspended schools, assigns memberships, hashes the shared password once with argon2id, and mirrors accounts to Neon when `DATABASE_URL` is set.
- <SourceFile path="apps/api/src/seed/demo-operations.ts" /> — timetable, leave, admissions, library, transport and hostel records tied to the demo accounts.
- <SourceFile path="apps/api/src/jobs/seed-demo.ts" /> — the `pnpm seed` command, its options and the printed sign-in table.
- <SourceFile path="apps/web/e2e/helpers.ts" /> — the Playwright tests sign in with these same accounts (`E2E_PASSWORD`, default `Schola@2026`).

Accounts are created with `emailVerifiedAt` already set (except the two
pending owners) and the `password` provider only.
